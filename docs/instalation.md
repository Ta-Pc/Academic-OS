# Academic OS Installation Guide

This guide provides step-by-step instructions for installing Academic OS (v6.0.2+) on your computer or mobile device.

## System Requirements

Before you begin, please ensure your device meets the following minimum requirements:

* **Windows:** Windows 10 or Windows 11
* **Android:** Android 8.0 (Oreo) or newer
* **iOS:** iOS 15 or newer
* **Web (macOS/Linux):** Any modern browser (Chrome, Edge, Safari, Firefox)

## Download the Latest Release

All installation files can be found on our GitHub Releases page.

📦 **[Download the Latest Release](https://github.com/Ta-Pc/Academic-OS/releases/latest)**

---

## 🖥️ Windows Installation (Desktop)

1.  Download the **`Academic-OS.exe`** file from the latest release.
2.  Double-click the downloaded file to run the installer.
3.  The application will install automatically and launch.

> **⚠️ Note: Windows Defender SmartScreen**
> You may see a blue "Windows protected your PC" screen. This is normal for new applications not yet signed by Microsoft.
> * Click **"More info"**.
> * Click the **"Run anyway"** button.

---

## 🤖 Android Installation (Native APK)

1.  Download the **`Academic-OS.apk`** file to your device.
2.  Tap the notification when the download completes, or locate the file in your **Downloads** folder.
3.  Tap to install.

> **⚠️ Note: "Install from Unknown Sources"**
> If this is your first time installing an app outside the Play Store, you will see a security prompt.
> * Tap **Settings** on the prompt.
> * Toggle on **"Allow from this source"** for your browser or file manager.
> * Go back and tap **Install**.

---

## 🍎 iOS Installation

### Option A: Native App (Advanced)
*Recommended for developers or users familiar with sideloading.*

1.  Download the **`AcademicOS.app`** (inside the zip file) from the release page.
2.  **Extract** the zip file.
3.  Install the `.app` using a sideloading tool (e.g., AltStore, SideStore, or Xcode if you have a Mac).
    * *Note: You may need to enable "Developer Mode" in your iPhone Settings under Privacy & Security.*

### Option B: Web App (Easiest)
*Recommended for standard users.*

1.  Open Safari and navigate to **[academic-os.pages.dev](https://academic-os.pages.dev)**.
2.  Tap the **Share** icon (box with an arrow pointing up).
3.  Scroll down and tap **"Add to Home Screen"**.
4.  Tap **Add**. The app will appear on your home screen and function exactly like the native version.

---

## 🌐 macOS & Linux (Web Version)

Currently, the native desktop app is optimized for Windows. For macOS and Linux users, we recommend using the Web Version or installing it as a PWA.

1.  Navigate to **[academic-os.pages.dev](https://academic-os.pages.dev)** in Chrome or Edge.
2.  **Chrome:** Click the "Install icon" (monitor with a down arrow) in the right side of the address bar.
3.  **Edge:** Click the App menu in the address bar and select **"Install Academic OS"**.
4.  The app will install to your system applications folder and can be launched like a native program.

---

## First Launch & Cloud Sync

After installation, open Academic OS.
1.  **Sign In:** You will be prompted to sign in with Google to enable Cloud Sync.
2.  **Onboarding:** The setup wizard will guide you through configuring your degree and importing any existing data from Google Drive.

## Having Trouble?

If you encounter issues:
* **Android:** Ensure you have enough storage space and have allowed installation permissions.
* **Windows:** Check your antivirus if the installer is blocked.
* **Bug Reports:** Please [open an issue on GitHub](https://github.com/Ta-Pc/Academic-OS/issues) with details about your device.
